Token usage is now emitted as numeric counters for structured attempts and remains available on invalid proposals. The final run measured all 216 attempts: 277,884 input tokens (277,236 reported cached), 58,301 output tokens (38,917 reported reasoning). Reasoning is part of output, not additional billed output. Monetary cost is not estimated without the provider's applicable rates; cancellation can leave unreported usage. Pilot cost limits and production full-turn latency remain release work, not inferred from this preflight measurement.

Live behavior variants are intentional: explicit mention/reply/ping/name requests have application-owned answer obligations; optional followup/group/reaction output needs interpretation and policy. All effects still pass the common service permit. The architecture suite rejects unauthorized imports of the guarded runner or permit issuer and requires live Discord adapters to consume approved snapshots. This catches ordinary architectural drift; it is not a sandbox against arbitrary newly written network code.

A real scheduler/adapter regression covers the reactor projection; numeric provider attempt/token telemetry replaces the callback. Per-turn admission budgeting remains unchanged. Full suite, typecheck, production compilation, changed-file lint, migration consistency and whitespace checks passed after these repairs.
