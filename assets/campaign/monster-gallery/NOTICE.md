# Monster gallery

Fallback portraits used when a monster's picture cannot be generated (no image budget left, or the image model failed). The bot never fetches these at run time.

- Source: https://github.com/lluc/dnd_pictures (`pictures_webp/monsters/`), copied unchanged.
- Author: lluc. License: MIT, see `LICENSE-lluc-dnd_pictures.txt`.
- Files: `goblin`, `wolf`, `bugbear`, `giant_wolf_spider` (`.webp`).

The pictures look AI-generated and not copied from any official book, but the repository does not say how they were made. If the author asks for removal, or a picture proves to copy published art, delete it here; the bot then simply goes without a fallback for that monster.
